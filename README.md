# Jacob & Co Website Clone

A static luxury watch brand website clone inspired by the official Jacob & Co website.
This project was built using only **HTML** and **CSS** while learning background images, layout design, and premium-style web aesthetics.

## Live Demo

[View Project](https://madhushreerasal.github.io/Jacob-and-Co-website-clone/)

## Features

* Luxury-inspired landing page design
* Multiple full-screen background image sections
* Fixed/parallax-style background effects
* Navigation bar and footer layout
* Typography-focused aesthetic
* Static website built without frameworks

## Technologies Used

* HTML5
* CSS3
* Remix Icon CDN

## What I Learned

While building this project, I practiced:

* Using background images in CSS
* Controlling image positioning and sizing
* Creating section-based layouts
* Working with floats and positioning
* Styling buttons and navigation elements
* Using overlays for readability
* Structuring larger static webpages
